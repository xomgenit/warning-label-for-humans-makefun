## Entry

> WARNING: Contents under pressure. Do not expose to Mondays, meetings, or anyone asking 'can I pick your brain?'

A single-line safety warning label that should come printed on every human being — 111 characters, inside the 1–160 gate.

## How it works

`main.ts` writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

```sh
node main.ts
```
